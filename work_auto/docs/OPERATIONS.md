# OPERATIONS — 운영·부하 점검

> 기준: 동시에 쓰는 사용자 100명 (2026-10, v0.9.5)

## 1. 어디서 무엇이 처리되나

| 작업 | 처리 위치 | 우리 서버 부담 | 비고 |
|------|-----------|----------------|------|
| 영상 파일 받기·소리 제거·글자 흐리게 | **사용자 브라우저** (ffmpeg.wasm) | 없음 | 영상은 서버를 지나가지 않는다. 트래픽 0 |
| 샤오홍슈 영상 주소 찾기 | 우리 서버 → 샤오홍슈 | 작음 (요청 1번, 1초) | ⚠️ 모든 사용자가 **같은 서버 IP** 를 쓴다 |
| 글자 위치 찾기 | 우리 서버 → AI (사용자 키) | 작음 (응답 기다림) | AI 비용은 각자 키 |
| 콘텐츠 생성·분석 | 우리 서버 → AI (사용자 키) | 작음 | |
| YouTube 트렌드 | 우리 서버 → YouTube (사용자 키) | 작음 | 할당량은 각자 키 (하루 10,000) |
| NAVER 데이터랩·검색광고 | 우리 서버 → NAVER (사용자 키) | 작음 | 데이터랩 하루 1,000회는 각자 키. 조회 1회(새 조건) ≈ 데이터랩 17회 → 하루 약 58번 새 조건 조회 (같은 조건 6시간 캐시) |
| NAVER 자동완성 | 우리 서버 → NAVER (비공식) | 작음 | ⚠️ 같은 서버 IP 를 쓴다 |
| DB | Supabase (서울) | 작음 | 텍스트만 저장 |

## 2. 위험 지점과 대응 (v0.9.5 에서 반영)

| 위험 | 대응 |
|------|------|
| 샤오홍슈·NAVER 자동완성이 서버 IP 를 막음 (한 사람이 반복 호출해도 모두 피해) | ① 사용자별 1분 호출 한도 (\`lib/server/rate-limit.ts\`) ② 샤오홍슈 결과 10분 기억 + 동시 요청 합치기 + 단축 링크 기억 ③ 자동완성 키워드별 6시간 기억 |
| AI 글자 찾기가 느려 서버 실행 시간(120초)을 넘김 | 화면 30장을 **10장씩 3번 동시에** 보내고, 실패한 묶음만 한 번 더. AI 호출은 100초가 넘으면 원인 안내와 함께 중단 |
| 요청이 커서 Vercel 4.5MB 제한을 넘김 | 한 번에 12장, 장당 200K 글자까지만 받는다 (보통 1장 40~80K) |
| 영상 엔진 CDN(unpkg) 장애 → 모든 사용자의 다운로드·흐리게 중단 | unpkg 가 안 되면 jsDelivr 에서 받는다 |
| 긴 영상 흐리게 → 브라우저가 수십 분 걸리거나 메모리 부족 | 글자 흐리게는 3분 이하 영상만 (다운로드는 제한 없음, 1GB 이하) |
| ffmpeg.wasm 엔진 멈춤 | 작업마다 새 엔진 + 한 줄로 순서대로 (\`runExclusive\`) |

| 이름 | 한도 | 이유 |

## 4. 다음 단계 (사용자가 더 늘면)

1. 샤오홍슈 차단 감지: 서버가 로그인 페이지로 돌아가는 비율을 기록 → 늘면 알림
2. 호출 한도를 Redis 로 (인스턴스 사이 공유)
3. 트렌드·샤오홍슈 결과 캐시를 DB 로 (인스턴스 사이 공유, 할당량 절약)
4. 글자 흐리게를 서버에서 처리하고 싶다면 별도 영상 처리 서버(GPU/CPU)가 필요하다 — 비용이 생기므로 사용량을 본 뒤 결정

## 5. 보안 (v0.9.7)

| 위험 | 대응 | 위치 |
|------|------|------|
| 사용자가 넣은 주소로 서버가 내부망에 접속 (SSRF) | 공개 인터넷 주소만 허용, 리다이렉트마다 재검사. 상품 URL 수집은 v0.9.11 에서 기능째 삭제 (사용자 주소로 접속하는 곳은 샤오홍슈 도메인 고정뿐) | `lib/server/security/safe-url.ts` (`safeFetch`, 새 기능용) |
| 샤오홍슈 주소 위장 (`evil.com/?xhslink.com`) | 도메인 정확히 비교 | `xiaohongshu-resolver.ts` `xhsHost()` |
| 클릭재킹·형식 추측 | 보안 헤더 | `next.config.ts` |
| 환경변수 실수로 데모(관리자) 모드가 운영에 열림 | production + Supabase 없음 → 503. 일부러 열려면 `ALLOW_DEMO=1` | `lib/supabase/config.ts` `isDemoBlocked()` |
| 비밀번호 대입·가입 폭주 | 15분 5회 초과 → Turnstile 캡차, 30회 초과 → 차단 | `lib/server/security/auth-guard.ts` |

캡차 키 설정: Cloudflare 대시보드 → Turnstile → Add widget (도메인 `work-auto-blush.vercel.app`) →
Vercel 환경변수 `NEXT_PUBLIC_TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY` → 재배포. 키가 없으면 캡차 대신 15분 차단.
