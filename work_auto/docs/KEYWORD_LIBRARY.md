# 키워드 관리 (v0.9.56)

뜨는 키워드(예: 아이폰듀오, 아이폰 Pro18)를 **제품과 묶어 6개월 수명**으로 관리한다. 제품 선정·원고 키워드에 쓴다.
위치: AI 학습 관리 › 키워드 관리 (`features/ai-learning/KeywordTab.tsx`). 서비스 `lib/server/services/keyword-library.ts`. 테이블 `trend_keywords`.

## 모으기
| 출처 | 언제 | 비용 |
|---|---|---|
| YouTube 트렌드 | 검색·급상승 결과의 태그·키워드 (영상 50개 × 5) — 응답 뒤(after) | 0 |
| NAVER 트렌드 | 급상승 키워드 + 급상승 주제 키워드 | 0 |
| Instagram | 새로 받은 릴스의 해시태그 (30분 기억 결과는 다시 안 셈) | 0 |
| 원고 생성 | Keyword Intelligence 후보 10개 → **고른 제품과 연결** | 0 |
| 스크랩 | 스크랩한 트렌드의 키워드·태그 | 0 |
| 직접 | 쉼표로 여러 개, 연결 제품 | 0 |
자동 수집은 실패해도 원래 기능을 막지 않는다. '추천·꿀팁·shorts' 같은 일반어, 숫자만, 2자 미만·30자 초과는 뺀다.

## 같은 말 묶음 (norm)
소문자 → 동의어(iphone→아이폰, galaxy→갤럭시, 프로→pro, 맥스→max, 울트라→ultra, 플러스→plus, 미니→mini) → 한글·영문·숫자 덩어리로 나눠 정렬.
→ 아이폰18프로 = 아이폰 Pro18 = iPhone 18 Pro. 다른 표기는 aliases 로 남긴다. (user_id, norm) 유일.

## 수명·상태
- 주별 본 횟수(weeks, 최근 26주) → 최근 2주 vs 그 전 2주: 상승(1.3배↑)·하락(0.7배↓)·유지, 처음 본 지 14일 안 = 새로 나옴
- **마지막으로 본 날 + 180일 → 보관함** (목록을 열 때 정리, 고정 제외, 지우지 않음). 다시 보이면 자동으로 살아남 (숨김은 그대로)
- [관심도 갱신]: 고른 최대 5개 → NAVER 데이터랩 1회, 상대 관심도(검색량 아님)와 방향

## 쓰기
- 원고 생성 화면: 제품을 고르면 `/api/keywords/suggest` (DB 만) → 상승·새로 나옴 먼저 15개 칩, 누르면 주요 키워드(블로그는 서브 키워드)에 추가
- 다음 단계 후보: 뜨는데 라이브러리에 없는 제품(제품 후보 이름) → 소싱 목록, 트렌드 화면에서 키워드 직접 담기 버튼
