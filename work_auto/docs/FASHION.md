# AI 패션 피드·릴스 (v0.9.103)

AI 패션 사진·영상 메뉴 (v0.9.116 부터 따로 메뉴, 주소는 그대로 `/instagram/fashion`, 기능 id `ig-fashion`).

## 레퍼런스 분석 (reference/fashion — 남의 릴스라 저장소·배포에서 제외)
- 릴스 20개: 대부분 10~15초, **같은 모델·같은 배경·같은 자리에서 옷만 바뀜** (LOOK1~6, 룩마다 1.5~3초, 하드 컷)
- 위쪽에 **POV 공감 한 줄**이 끝까지 고정 (흰 상자 + 검은 글자), 작은 LOOK 라벨, 룩마다 한 줄 설명, 음악만
- 배경: 엘리베이터·호텔 복도·전신거울·거리·한옥 골목·한강 야경 — 영상 하나에 1개
- 피드 4장: 미색 배경, 왼쪽 착용 / 오른쪽 옷·신발 제품컷, 'LOOK 01' 타원 라벨

## 흐름
1. 상품: 사진 올리기(여러 장) + 이름·종류·쿠팡 링크 / 제품 라이브러리에서 가져오기(쿠팡 호출 없음, 대표 이미지만 받아 둠)
2. 모델: AI(글) 또는 실제 사진 → '살짝 다른 얼굴'(Nano Banana Edit, 참고 사진 1장). 승인 1장 = 모든 룩의 얼굴 기준
3. 배경·문구: 배경 프리셋(`BACKGROUNDS`), POV, 댓글 안내. [AI 로 문구 쓰기 + 룩 묶기] = AI 글 1회
4. 룩: 상품 고르기·한 줄 설명·자세 → Nano Banana Edit (참고 = 모델 1장 + 그 룩의 상품 사진 최대 6장), 9:16
5. 결과물 (외부 비용 없음): 피드 카드 1080×1350 PNG(표지 + 룩마다), 릴스 (가) 1080×1920 MP4 (룩마다 N초 zoompan 1.00→1.06 + POV·LOOK·설명 PNG + 마지막 CTA 2.5초 + 음악). (나) AI 영상은 다음 단계

## 저장 (DB 변경 없음)
Storage `videos` 버킷: `{owner}/fashion/index.json`, `{owner}/fashion/{fp_…}/rev/{번호}_{임의}.json`(최근 15개), `up|img|bgm|out/…` 파일.
화면 저장(PATCH)은 부분별, 이미지 목록은 승인·지우기만 반영하고 서버에만 있는 새 이미지는 지킨다. 작업 결과 저장은 최신 문서에 '이번에 새로 생긴 것'만 합친다.

## 비용·안전
- Kie 이미지 1장 = 1회(약 4크레딧), Suno 음악 1회 — 확인 창(`confirmed:true`) 후에만, 같은 요청 번호 재사용, 자동 재시도 없음, 진행 확인(recordInfo)은 무료
- 결과 파일은 https + 내부망 차단(safeFetch), 크기 제한
- 글꼴(Pretendard)에 없는 이모지는 그리지 않는다 (`plainText`)
