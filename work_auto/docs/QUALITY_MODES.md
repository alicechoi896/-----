# 생성 품질 1단계: 대본 뼈대 · 정밀 생성 (v0.9.31)

영상·클립 원고(YouTube 제품·정보성 영상, NAVER 클립 제품·정보성)의 품질을 높이는 첫 단계입니다. 블로그에는 적용하지 않습니다. DB 변경은 없습니다.

## 1. 대본 뼈대 (모든 생성)

프롬프트 1.12.0의 `SCRIPT_SKELETON` 규칙입니다(`lib/server/ai/prompts/templates.ts`). 빠른 생성과 정밀 생성 모두 이 규칙을 따릅니다.

1. 첫 3~5초(첫 1~2줄)는 **질문·반전·손해 경고** 중 하나로 연다. 인사나 "오늘은 ~를 소개합니다"로 시작하지 않는다.
2. 중간에 **오픈 루프**(끝까지 볼 이유)를 하나 연다.
3. 열어 둔 궁금증의 **답은 끝부분**에 준다.
4. 한 줄에는 정보 하나만 쓴다. 스펙을 나열하는 대신 **쓰는 장면**으로 말한다.

## 2. 생성 방식

생성 폼의 버튼 위에서 고릅니다. 정밀 생성은 대본·제목·Hook이 있는 기능에서만 보입니다(`supportsPrecise`, `lib/generators/quality.ts`).

| | 빠른 생성 (기본) | 정밀 생성 |
|---|---|---|
| AI 호출 | 1회 | 4회 (호출 한도는 1회로 셈) |
| API | `POST /api/contents/generate` | `POST /api/contents/generate/precise` (NDJSON 스트림, maxDuration 300초) |
| 제목 | 10개 | 40개 → 추천 TOP 5(이유)를 맨 앞에, 나머지는 접어서 표시 |
| 대본 | 3편 | 앵글 3개에 하나씩 → 검토·수정 → 대본마다 뼈대 체크·검토 메모 |

### 정밀 생성 단계 (`contentGenerationService.generatePrecise`)

모든 단계가 같은 Generation Context·콘텐츠 프롬프트를 쓰고, 단계별 지시만 덧붙입니다.

1. **앵글** (`content.precise-angles` 1.0.0): 서로 다른 앵글 3개를 정하고 이름과 이유를 붙입니다.
2. **제목·Hook** (`content.precise-titles` 1.0.0): 앵글별로 제목 40개를 만들고, 스스로 비교해 `title_top` 5개(번호와 이유)를 고릅니다. Hook은 앵글마다 3개 이상 버전을 만듭니다.
3. **대본** (콘텐츠 프롬프트 + 단계 지시): 대본 i는 앵글 i를 따르고, 추천 제목의 약속을 지키게 하며, Hook 후보를 참고합니다. 나머지 항목(CTA·설명글·키워드·태그 등)도 이 단계에서 함께 만듭니다.
4. **이탈 지점 검토** (`content.precise-review` 1.0.0): 편집장 역할로 대본을 고치고 hook·open_loop·answer를 판정하며, 검토 메모를 씁니다.
   - 사실·말투·분량은 그대로 두고 고칩니다.
   - 고친 대본이 원래 길이의 절반 미만이면 잘린 것으로 보고 원래 대본을 씁니다.
   - 이 단계가 실패하면 3단계 대본으로 저장하고, 결과 메모에 그 사실을 남깁니다.

### 저장 형식

`contents.context.quality`(jsonb, 기존 컬럼)에 아래처럼 저장합니다.

```ts
{ mode: "precise", angles: [{name, why}], titleTop: [{title, reason}], scripts: [{ key, angle, checks: {hook, openLoop, answer}, review }] }
```

- 추천 제목은 문자열로 저장합니다. [추가 만들기]나 직접 수정으로 목록이 바뀌어도, 지금 목록에 남아 있는 추천만 보여 줍니다.
- 대본 메타는 `scriptMetaKey`(공백·기호를 뺀 앞 80자)로 대본과 짝을 맞춥니다. [추가 만들기]로 새로 생긴 대본에는 메타가 없습니다.

### 화면

- **진행 표시**: 서버가 단계를 시작할 때마다 `{"type":"stage"}` 줄을 보냅니다. 화면은 4단계 목록에 완료·진행 중 표시를 합니다.
- **결과**: 제목 칸에 ★ 추천 TOP 5와 각 이유를 보여 주고, 나머지는 [나머지 35개 보기]로 펼칩니다. 대본 카드에는 앵글, 뼈대 체크 칩(빠지면 노란색), 검토 메모를 보여 줍니다.
