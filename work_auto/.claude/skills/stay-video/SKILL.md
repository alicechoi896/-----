# AI 숙소 영상

## 파일
- 화면 `features/ai-stay/StayStudio.tsx` · API `app/api/stay/route.ts` (action 하나씩) · 서버 `lib/server/stay/service.ts` · 시간표 `lib/server/video/stay-timeline.ts` · 렌더는 `render.ts` 의 `plan.stay` 분기.
- 프로젝트: `{owner}/stay/projects.json` (DB 아님). 사진 `{owner}/stay/{id}/p*.jpg`(9:16), 미리보기 `clip_*.mp4`(1시간).

## 흐름
1. 숙소 고르기(제품 라이브러리 분류 '숙소'의 내 사진) → 사진은 **장소(원본)마다 묶음**, 장소마다 [다른 각도 컷 만들기] (nano-banana-edit, 원본 바로 뒤에 들어감).
2. ② 제목·대사: 고른 **대본 포맷**을 따름 (`stayFormat`). 대사는 다음 컷으로 이어지는 흐름 ('숲길을 따라 들어가면' → …), 퀴즈로 끊지 않음, '~니다.' 금지. 움직임 명령어는 무엇이 어떻게 움직이는지 2~3가지 영어 + 한글.
3. ③ 살아 움직이게: `MOTION_RULE` — 카메라 고정(**줌·push-in 없음**), 장면 속 요소가 처음부터 끝까지 사실적으로 계속 움직임. 컷마다 [움직임 다시 만들기] (그 컷만).
4. ④ 목소리(타입캐스트/OpenAI) + **말하기 속도**(화면 값 그대로, 기본 2배) → [영상 만들기].

## 렌더 규칙
- 영상과 대사는 따로: 컷은 정한 시간(자동 1.6초~, 최대 5초)대로 이어지고, 대사는 대사 있는 줄만 읽어 이어 붙인 음성을 컷 시간대로 자름. **대사 없는 컷(각도 컷)도 영상에 들어감**.
- AI 컷은 5초 중 **가운데 구간**을 씀 (처음 1초는 거의 안 움직임). AI 컷은 `framerate=fps=30` 으로 사이를 섞어 채움 (뚝뚝 끊김 방지). 음악 없음.
- 이 분기는 `job.plan.stay` 일 때만 — 가전 영상은 그대로.

## 사용자가 겪었던 문제 (다시 생기지 않게)
- 고친 대사·움직임이 되돌아감 → 화면 요청은 `callQ` 로 차례로, 고친 값은 바로 화면에, 상태 확인 응답은 그사이 저장했으면 버림. 서버는 저장 직전에 다시 읽어 그 프로젝트만 바꾸고(`save`), 상태 확인은 바뀐 것만 얹음(`saveStatus`).
- 새 영상 만들기·지우기가 되돌아감 → 위와 같은 원인 (오래 걸리는 상태 확인이 예전 목록을 덮음).
- 다시 만들기가 다른 컷까지 만듦 → `animate({ keys })` 는 그 컷만.
- 줌만 되고 멈춤, 끊김 → MOTION_RULE·가운데 구간·framerate.
- 테스트: tests/api 의 stay 부분, 흐름 시험은 데모로 (실제 Kie 결과는 사용자에게 1컷 먼저 확인 부탁).
